# One Line, One Minute: The Vending Machine Pickup Line Contest

One original pickup line, at most 200 characters, as if a vending machine were flirting with a passing human.

Entry: `Hey, I have been holding your favourite snack at eye level all day, and unlike your ex, I always give exact change.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
